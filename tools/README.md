# Программы репозитория

Здесь лежат тексты программ (скриптов на Python) и их тесты. Программы собирают табло, страницу «что сейчас» и каталог выпусков, проверяют решения Выпускающего и печатают чек-лист выпуска. Пишет и правит их Разработчик; правку одобряет его команда ([кто куда пишет](../team/README.md#кто-куда-пишет)).

| Файл | Что делает |
|---|---|
| [build_board.py](build_board.py) | собирает табло (`board/`), страницу [NOW.md](../NOW.md) и каталог выпусков; проверяет ссылки и актуальность собранного |
| [iwe_stats.py](iwe_stats.py) | считает результаты крупными цифрами для [board/stats.md](../board/stats.md) |
| [release_catalog.py](release_catalog.py) | собирает каталог выпусков из [releases/index.yaml](../releases/index.yaml) |
| [check_decisions.py](check_decisions.py) | проверяет форму решений Выпускающего (`decisions.md` папки выпуска), а после слияния выпуска — что отложенное вернулось в основную ветку шаблона |
| [changelog.py](changelog.py) | разбирает журнал изменений шаблона по разделам и даёт записям ключи `U-…`; общий для сборщика табло и проверки решений |
| [release-checklist.py](release-checklist.py) | печатает сводку по выпуску: каждая строка протокола, кто и когда её отметил, последний вердикт атаки и итоговое решение Выпускающего; с ключом `--closure` проверяет, закрыт ли выпуск: читает `checklist.md` папки выпуска и печатает строки действий 17а–28, где состояние не «да» и не «не нужно» (в том числе «нет», «частично», «идёт», пусто); пока такие есть, возвращает код 1 |
| [layout.py](layout.py) | единое место, где записаны пути, которые читают и пишут программы |
| `test_*.py` | тесты программ выше |

Команды запуска — [в функционально-модульном описании](../method/functional-modular.md#команды). Тесты: `python -m pytest -q tools`.

**Выпуск закрыт?** Перед записью итога выпуска (действие 28) запустить `python3 tools/release-checklist.py --closure --release <N>`. Программа печатает, например, «Выпуск 0.42.2 не закрыт: открыты строки 20, 25, 26, 27, 28» и по каждой строке состояние из чек-листа; код возврата 1, пока открыта хотя бы одна строка, и 0, когда все строки 17а–28 отмечены «да» или «не нужно». Строка действия 17 (слияние и метка) в проверку не входит: это сам выход выпуска.
