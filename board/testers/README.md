# Отметки проверки

Один файл на одну сборку: `<N>-rc.<K>.yaml`, например `0.42-rc.1.yaml`. Новая сборка — новый файл; отметки прошлой сборки не переносятся.

```yaml
build: 0.42-rc.1
marks:
  - line: 1                 # номер строки протокола releases/<N>/protocol.md
    result: пройдено        # пройдено | не пройдено | не проверялось
    tester: <логин GitHub>
    note: ""                # пересказ без имён и личных данных
```
