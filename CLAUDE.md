# DS-iwe-releases — правила для ИИ-агентов

Открытый репозиторий команды выпуска шаблона IWE. Суть, роли и порядок работы — в README.md.

## Обязательно

- **Без личных данных.** Людей указывать только логином GitHub; почту, телефоны, обращения пользователей с их данными не писать. Обращение пользователя — пересказом без имени. Секретов и ключей здесь нет и не будет.
- **Только свой файл роли.** Агент Разработчика правит `roles/developer.yaml`, `roles/developer-links.yaml`, `roles/developer-handoff.yaml` и `releases/<N>/README.md`, Выпускающего — `roles/release-lead.yaml` и `releases/<N>/decisions.md`, тестировщика — `releases/<N>/tests/`. Чужой файл не трогать.
- **`now/`, `releases/<N>/shipped.md` и `releases/<N>/candidates.md` руками не править** — их собирает программа `tools/build_board.py`. `now/` — оперативное, переписывается целиком; `releases/<N>/` — накопительное, после выхода выпуска не меняется.
- **Статус — только из закрытого списка** в README, раздел «Стадии и статусы». Новый статус — сначала правка README через запрос на слияние.
- **Все правки — через запрос на слияние**, не прямой отправкой в main.
- Номера целей и коды результатов не придумывать: цели — из «Целей и сценариев» (DP.MAP.005), коды — из «Состояния по целям».
