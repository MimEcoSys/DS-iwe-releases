# DS-iwe-releases — правила для ИИ-агентов

Открытый репозиторий команды выпуска шаблона IWE. Суть, роли и цикл выпуска — в README.md.

## Обязательно

- **Без личных данных.** Людей указывать только логином GitHub; почту, телефоны, обращения пользователей с их данными не писать. Обращение пользователя — пересказом без имени. Секретов и ключей здесь нет и не будет.
- **Только свой файл роли.** Агент Разработчика правит `board/developer.yaml`, Выпускающего — `board/release-lead.yaml` и `releases/`, тестировщика — `board/testers/`. Чужой файл не трогать.
- **`view/` руками не править** — его собирает программа (`tools/first_fill.py`, позже сборщик табло Ф253).
- **Статус — только из закрытого списка** в README, раздел «Табло». Новый статус — сначала правка README через запрос на слияние.
- **Все правки — через запрос на слияние**, не прямой отправкой в main.
- Номера целей и коды результатов не придумывать: цели — из «Целей и сценариев» (DP.MAP.005), коды — из «Состояния по целям».
