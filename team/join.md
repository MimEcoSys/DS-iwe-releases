# Как присоединиться к команде выпуска

Команда выпуска проверяет новые версии шаблона IWE до того, как их получат все пользователи, и решает, что выходит. Присоединиться может любой участник МИМ с аккаунтом GitHub.

## 1. Выбери роль

Посмотри [перечень ролей](README.md#роли). Чаще всего начинают с роли тестировщика: она не требует знать код шаблона, нужен только компьютер, на котором можно поставить IWE с нуля.

## 2. Прочитай инструкцию роли

- Тестировщику — [вход для тестировщиков](tester/README.md).
- Выпускающему — [с чего начать](release-lead/start.md).
- Как устроен выпуск целиком — [схема конвейера](../method/pipeline.md).

## 3. Напиши Выпускающему

В Telegram или в теме «Выпуск <N>» Зулипа МИМ: какую роль берёшь и твой логин GitHub. Выпускающий добавит тебя в команду организации MimEcoSys (`iwe-testers`, `iwe-release-lead` или `iwe-developers`) и назовёт текущую сборку-кандидат — она же на странице [«что сейчас»](../NOW.md).

Почту, телефон и другие личные данные сюда не пиши: репозиторий открытый, людей в нём указывают только логином GitHub.

## 4. Первая правка

Каждая роль пишет только в свой файл ([кто куда пишет](README.md#кто-куда-пишет)). Правка идёт запросом на слияние: на GitHub открой нужный файл → кнопка с карандашом → внеси правку → «Propose changes» → «Create pull request». Перед слиянием запрос проверяют автоматические проверки и человек из команды, отвечающей за этот файл.

Если ты ещё не в команде, пришли файл Выпускающему — Разработчик положит его без правок, а автором останешься ты.
