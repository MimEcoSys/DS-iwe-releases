# Рецензент выпуска

**Кто:** ИИ-агент.

**Что делает.** Судит поверх вывода программ проверки, со ссылками «файл:строка»; не решает. Его «нет» и причина, по которой Выпускающий его переопределил, записываются.

**Где в схеме.** [этап 6 «Рецензия»](../../method/pipeline.md#этапы): результат — замечания или «нет замечаний».

**Куда записывает.** `releases/<X>.N/<N>/decisions.md` (записывает Выпускающий по его суждению).

Общий перечень ролей и кто куда пишет — [team/README.md](../README.md).
