# Тестировщикам

Здесь хранят инструкции тестировщикам. Тестировщик ставит сборку-кандидат на свой компьютер, проходит строки протокола проверки и пытается её сломать; его отметки решают, выходит ли выпуск.

## С чего начать

1. Узнай, какую сборку проверяем сейчас, — страница [«что сейчас»](../../NOW.md) или Выпускающий.
2. Открой инструкцию для своей системы:
   - [macOS](tester-macos.md) — пошагово, со снимками экрана; 1–2 часа;
   - [Linux](tester-linux.md) — готовые команды, для агента на сервере или опытного человека.
3. Протокол проверки (какие строки и что считается пройденным) — `protocol.md` в папке текущего выпуска.

## Куда класть результат

Одна папка на сборку-кандидат: `tests/rc.<K>/` в папке выпуска (например, [папка проверок 0.42](../../releases/0.N/0.42/tests/README.md)). В ней — файл отметок `<платформа>-<логин>.yaml`, отчёт атаки, журналы. Формат файла отметок — в README папки проверок выпуска. Новый кандидат — новая папка: отметки прошлого кандидата не переносятся.

Перед запросом на слияние проверь, что в журналах нет личных данных: `python3 .github/scripts/pii_scan.py`.
