# Разметчик кодов

**Кто:** ИИ-агент или Разработчик.

**Что делает.** У каждой записи раздела версии в `CHANGELOG.md` на ветке выпуска ставит код обещанного результата или пометку «служебное — причина». Полноту проверяет программа шаблона `scripts/check-changelog-fields.py`, а не человек.

**После включения этапа «Разметка изменений» (РП-529 Ф282)** записи основной ветки размечает Разработчик на этом этапе; роль остаётся для исправлений, сделанных на ветке выпуска.

**Где в схеме.** [этап 2 «Поля и коды»](../../method/pipeline.md#этапы): результат — раздел версии размечен полностью.

**Куда записывает.** `CHANGELOG.md` на ветке выпуска в шаблоне. Своего файла в этом репозитории у роли нет.

Общий перечень ролей и кто куда пишет — [team/README.md](../README.md).
