# Проверяющий red team

**Кто:** Назначает Выпускающий; не автор кода выпуска.

**Что делает.** Независимо атакует сборку-кандидат по навыку шаблона `iwe-platform-redteam`: сначала калибровка на заведомо плохой и заведомо хорошей сборке, затем атака на одноразовой копии — установка, обновление, откат, права агента, защитные проверки.

**Где в схеме.** [этап 9 «Red team»](../../method/pipeline.md#этапы): результат — вердикт `GO` / `CAUTION` / `BLOCKED` или `cannot_verify` для дерева этого кандидата.

**Куда записывает.** блок `red_team` в файле отметок `releases/<X>.N/<N>/tests/rc.<K>/` и комментарий в запросе на слияние.

Общий перечень ролей и кто куда пишет — [team/README.md](../README.md).
