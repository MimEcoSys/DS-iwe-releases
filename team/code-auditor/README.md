# Аудитор кода

**Кто:** ИИ-агент, только чтение.

**Что делает.** Читает разницу выпуска `v<P>...v<N>-rc.<K>` и сообщает об ошибках, рисках обновления и отката, лишних правах агента; не решает.

**Где в схеме.** [этап 7 «Аудит кода»](../../method/pipeline.md#этапы): результат — находки в теме выпуска.

**Куда записывает.** Разработчик переносит находки в запрос на слияние. Своего файла в этом репозитории у роли нет.

Общий перечень ролей и кто куда пишет — [team/README.md](../README.md).
