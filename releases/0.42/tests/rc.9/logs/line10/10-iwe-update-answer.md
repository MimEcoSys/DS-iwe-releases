## Что изменилось: 0.41.11 → 0.42.0

У вас установлена версия 0.42.0. Главное в ней: два новых навыка, более строгая защита от опасных команд агента и более надёжное обновление. Ниже основное из описания выпуска и полного списка изменений.

**Что нового:**
- **Поиск метода** (`/find-method`, пока экспериментальный). Вы описываете затруднение, агент подбирает способ действия из FPF и ваших паков, показывает точную цитату из источника и проводит по шагам. Если подходящего метода нет, он так и скажет и не станет выдумывать план.
- **Лёгкий онбординг** (`/onboarding`). Новый человек за один разговор разбирает свою задачу методом из библиотеки, и его не нагружают правилами среды.
- **Уведомления в Telegram** теперь отправляет одна команда. Можно подключить свой шлюз уведомлений, тогда рутинные сообщения приходят одной сводкой.
- **Linux и WSL2:** установка снова сама ставит фоновые роли (Стратег, разборщик заметок), настраивать вручную не нужно.

**Что изменилось в поведении:**
- **Агенту запрещено больше опасных действий без вашего участия.** Он не может массово удалять найденные файлы, через поиск запускать что-либо, кроме чтения, удалять ветки, менять адрес хранилища и затирать файлы защитных проверок. Если агент раньше делал что-то из этого сам, теперь он остановится.
- **Возврат к старой версии всегда требует подтверждения:** нужно ввести `ROLLBACK`, на любом канале обновления. Файлы новой версии после возврата убираются в резервную копию.
- **«Заливай» и «запуши» больше не запускают закрытие сессии.** Агент только сохранит изменения и отправит их в хранилище.
- Агент читает в карточке рабочего продукта только открытые этапы. Раньше так было только для крупных составных карточек, теперь для любой.
- Новый рабочий продукт можно заводить без строки в плане недели: для этого есть параметр в файле настроек.

**Исправления:**
- На Windows (Git Bash) обновление больше не останавливается после первого записанного файла.
- Учёт времени через WakaTime снова показывает сумму за день: сервис начал отказывать в старом способе запроса.
- Закрытие сессии больше не падает на конфликте при отправке изменений.
- Проверка актуальности хранилищ на обычной установке больше не падает с ошибкой «файл не найден».

**Известные ограничения**, о которых предупреждают авторы:
- Агент может без запроса прочитать файл с ключами внутри папки IWE, например `.env`. Храните ключи вне папки IWE, например в `~/.secrets/`. Так было и в 0.41.11, исправление готовится.
- Проверка опасных команд смотрит только на текст команды. Путь, спрятанный в переменную, она не распознаёт.
- Ручная проверка этой версии на macOS ещё идёт.

Подробнее можно прочитать в описании выпуска (`FMT-exocortex-template/docs/releases/0.42/README.md`) и в полном списке изменений, раздел `[0.42.0]` (`FMT-exocortex-template/CHANGELOG.md`).

Ваш вызов команды среды я засчитал как просьбу о работе в среде и поэтому отметил вводный онбординг пройденным. Вернуть его можно командой `bash .claude/scripts/light-onboarding-state.sh reset`.
