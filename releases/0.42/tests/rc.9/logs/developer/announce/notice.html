🔄 Обновление шаблона IWE 0.42.0 1. Лёгкое знакомство для новичка — Новый человек за один разговор разбирает свою задачу методом из локальной библиотеки и получает итог «было → стало». Без аккаунта, без подписки и без обращений к платным сервисам. 2. Поиск подходящего метода — Новый экспериментальный навык подбирает способ действия под ваше затруднение из локальных библиотек и ваших паков. Он показывает кандидатов с дословным фрагментом и ведёт по шагам, а если метода нет, честно об этом говорит. 3. Надёжнее защита от удаления — При поиске файлов агент теперь может запускать только команды, которые читают. Раньше через поиск можно было без запроса удалять, перемещать и переписывать файлы. 4. Правки памяти не теряются — Если вы правили файл памяти прямо в папке шаблона, обновление перед заменой сохраняет его копию и показывает, где она лежит. Если копию сохранить не удалось, обновление не начинается. 5. Уведомления в Telegram снова работают — Обновление теперь даёт право на запуск всем доставленным программам. Раньше после обновления с 0.41.11 переставали уходить уведомления синхронизатора и стратега в Telegram. 6. Установка на Linux и WSL2 — Установка на Linux, в том числе в WSL2, снова сама настраивает автоматический запуск ролей. Раньше Стратег с выбранным временем утреннего запуска не включался, и его приходилось настраивать вручную. Все изменения выпуска Как обновить: скажите своему Claude «обнови мой экзокортекс» или выполните в терминале bash update.sh
