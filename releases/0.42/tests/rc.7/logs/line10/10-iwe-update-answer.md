Я прочитал список изменений и описание выпуска, которые пришли вместе с установкой.

## Что изменилось: 0.41.11 → 0.42.0 (установлена у вас)

Главное: в 0.42 появился поиск метода под вашу задачу, агенту запрещено больше опасных команд, а обновление и откат стали надёжнее. Этот выпуск сначала собрали как пробную версию (кандидата), её проверили тестировщики и независимая атака.

**Что нового:**
- **Поиск метода** (навык `/find-method`, пока экспериментальный). Вы описываете затруднение, агент подбирает способ действия из FPF и ваших паков, показывает дословный фрагмент источника и ведёт по шагам. Если подходящего метода нет, он так и скажет, а не станет его придумывать.
- **Лёгкий онбординг** (навык `/onboarding`). Новый человек за один разговор разбирает свою задачу методом из библиотеки, а правила рабочей среды его не касаются.
- **Уведомления в Telegram** теперь идут через одну общую команду. Можно подключить свой шлюз уведомлений, тогда рутинные сообщения приходят одной сводкой.
- **Linux и WSL2.** Установка снова сама ставит фоновые роли (Стратега и разборщика) как службы, настраивать их вручную больше не нужно.

**Что изменилось в поведении:**
- **Агент без вашего участия больше не может:** удалять всё найденное поиском, писать в файлы через хитрые формы команд `git` и `find`, запускать через поиск что-то кроме чтения, удалять ветки, менять адрес хранилища и затирать файлы защитных проверок. Если раньше агент делал что-то из этого сам, теперь он спросит вас.
- **Обновление:** доставленные программы сразу получают право на запуск. Возврат на прошлый выпуск на любом канале требует ввести слово `ROLLBACK`, а с ключом `--yes` откат не выполнится. После отката файлы новой версии, которые вы не меняли, переносятся в резервную копию.
- **Новые рабочие продукты** можно не добавлять в план недели автоматически, для этого появился отдельный флаг и параметр.
- **«Заливай» и «запуши»** теперь просто отправляют изменения в хранилище и не запускают закрытие сессии.
- **Правило «читать только открытые фазы»** раньше касалось только зонтичных рабочих продуктов, теперь по умолчанию действует для карточки любого рабочего продукта.

**Исправления:**
- Проверка свежести хранилища при первом обращении к нему больше не падает на обычной установке.
- На Windows (Git Bash) обновление больше не останавливается после первой записи.
- Закрытие сессии больше не падает на конфликте при отправке.
- Подсчёт времени через WakaTime снова работает после того, как сервис перестал принимать прежний ключ.
- Проверка содержимого больших коммитов больше не тянется десятки минут.
- Разборщик и закрытие месяца работают стабильнее.

**Известные ограничения:**
- **Секреты.** Команды чтения разрешены без подтверждения, поэтому агент может прочитать, например, файл `.env` внутри папки IWE. Так было и в 0.41.11. Ключи лучше держать вне папки IWE, например в `~/.secrets/`.
- **Проверка опасных команд** видит только текст команды. Если путь спрятан в переменную, она его не распознает.
- **macOS и Windows.** Программы на серверах GitHub проверили сборку на всех трёх системах, а вручную её проверили только на Linux. Ручная проверка на macOS ещё идёт.
