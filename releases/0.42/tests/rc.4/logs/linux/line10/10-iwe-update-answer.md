## Обновление IWE: 0.41.11 → 0.42.0

У вас установлена версия 0.42.0 от 10.11.2026. Главное в ней: обновление стало безопаснее и больше не откатывает установку молча, защита от опасных команд агента стала строже, появились два новых навыка. Ничего не нужно делать вручную, всё должно работать как раньше.

**Что нового:**
- **Навык «Найти и применить метод» (`/find-method`, пока экспериментальный).** Вы описываете затруднение («как подойти к…»), агент подбирает способ действия из ваших локальных баз знаний, показывает дословный фрагмент источника и ведёт по шагам. Если подходящего метода нет, он так и скажет.
- **Лёгкий онбординг (`/onboarding`).** Новый человек за один разговор разбирает свою задачу методом и получает итог «было → стало». Пока онбординг не пройден, агент не грузит человека правилами среды.
- **Единая команда для уведомлений в Telegram.** Все сообщения от фоновых ролей теперь идут через одну точку. Если подключить свой шлюз уведомлений, рутинные сообщения можно собирать в сводку и не получать каждое отдельно в чат.

**Что изменилось (это можно заметить):**
- **Обновление не возвращает файлы к старой версии.** Раньше на установке новее выпуска обновление могло тихо откатить файлы к 0.41.11. Теперь оно распознаёт такой откат на любом канале обновления и без вашего подтверждения его не выполняет.
- **Строже проверка опасных команд агента.** Под запретом массовое удаление через поиск файлов (`find -delete`, `xargs rm`) и команды, которые пишут в файл через свой аргумент. Вместе с командой поиска (`find -exec`) теперь разрешены только команды, которые читают. Если агент упрётся в такую блокировку, это ожидаемо.
- **Новый РП можно не добавлять в план недели.** Для этого есть параметр `wp_new_add_to_weekplan: false` в файле параметров.
- **Агент реже читает закрытые этапы РП.** По умолчанию он читает только открытые этапы любой карточки РП, закрытые открывает по вашей просьбе или когда они нужны для задачи.
- **Фразы «заливай» и «запуши» больше не запускают закрытие сессии.** Агент сохраняет работу и отправляет её в хранилище, закрытие не начинает.

**Исправления:**
- Обновление на Windows (Git Bash) больше не останавливается после первой записи. Репетиция протоколов там тоже заработала.
- Установка на Linux и WSL2 снова сама ставит фоновые роли, раньше этот шаг пропускался.
- Проверка свежести хранилищ при первом обращении больше не падает с ошибкой «файл не найден».
- Навык разбора находок (`apply-captures`) больше не падает на шагах 1 и 6, а дубли ищет по вашей базе знаний.
- Подсчёт времени через WakaTime снова работает: сервис перестал принимать старый способ запроса.
- Служебные отметки открытия и закрытия дня снова закрываются на второй и следующие дни.
- Уборка памяти перестала пропускать файлы без даты и снова укладывается во время шага закрытия месяца.

Ещё в выпуске много правок для авторов шаблона (выпуск только через проверенного кандидата, перевод на английский, словарь терминов). На вашу работу они не влияют.

**Оговорки:**
- **Откуда я взял список.** Описание изменений по метке выпуска 0.42.0 на GitHub не нашлось: страница ответила «не найдено», есть только метки кандидатов. Поэтому я взял локальную копию описания из папки шаблона, которую положило само обновление. Если вы ставили кандидата, а не выпуск, состав может немного отличаться.
- **Онбординг.** Вы вызвали команду среды, поэтому я отметил лёгкий онбординг как пройденный. Вернуть его можно командой `bash .claude/scripts/light-onboarding-state.sh reset`.

Я ничего не устанавливал и не менял, только прочитал описание изменений.
