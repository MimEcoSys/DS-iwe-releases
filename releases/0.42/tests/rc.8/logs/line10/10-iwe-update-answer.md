## Обновление IWE: 0.41.11 → 0.42.0

У вас установлена версия 0.42.0. Описание взято из списка изменений и описания выпуска, которые пришли вместе с обновлением в папку шаблона.

**Что нового:**
- **Поиск метода** (`/find-method`, пока экспериментальный). Вы описываете затруднение, агент подбирает способ действия из FPF и ваших паков, цитирует источник дословно и ведёт по шагам. Если подходящего метода нет, он прямо об этом скажет и не станет сочинять план.
- **Лёгкий онбординг** (`/onboarding`). Новичок за один разговор разбирает свою задачу методом из библиотеки, и правила рабочей среды его при этом не нагружают.
- **Уведомления в Telegram** теперь идут через одну команду. Можно подключить свой шлюз уведомлений, тогда рутинные сообщения собираются в сводку.
- **Linux и WSL2.** Установка снова сама ставит фоновые роли (Стратег, разборщик) через системные службы или cron, вручную настраивать ничего не нужно.

**Что изменилось:**
- **Агент без вашего участия может сделать меньше опасного.** Ему запрещено массово удалять найденные файлы, писать в файлы обходными путями через `git` и `find`, запускать через `find` что-либо, кроме чтения, удалять ветки, менять адрес хранилища и затирать файлы защитных проверок. Если вы привыкли, что агент делает такое сам, теперь он будет останавливаться.
- **Откат на старую версию** всегда требует ввести `ROLLBACK`, на любом канале обновления. После отката файлы более новой версии убираются в резервную копию, а файлы, которые вы меняли, остаются на месте.
- **Новый рабочий продукт** можно не добавлять в план недели. Для этого есть флаг `--no-weekplan` и параметр `wp_new_add_to_weekplan: false` в файле параметров.
- Слова «заливай» и «запуши» больше не запускают закрытие сессии, они означают только «сохрани и отправь».
- Правило «читать только открытые фазы» теперь по умолчанию действует для любой карточки рабочего продукта.

**Исправления:**
- Обновление больше не могло откатить 81 файл без вашего подтверждения, если на установке стояла версия новее выпуска.
- Обновление больше не останавливается после первой записи в Git Bash на Windows, а у доставленных программ появляется право на запуск, как на чистой установке.
- Свои правки в файлах памяти внутри папки шаблона обновление сохраняет, прежде чем заменить файл.
- Подсчёт времени из WakaTime снова работает: сервис стал отказывать в запросе сводок, и подсчёт перевели на другой способ.
- Исправлено несколько мелких падений: проверка свежести хранилища на обычной установке, сканирование кода без хранилищ `DS-*`, закрытие сессии при конфликте.

**Известные ограничения (из описания выпуска):**
- Агент может без запроса прочитать файл с ключами (например, `.env`) внутри папки IWE, потому что команды чтения разрешены без подтверждения. Так было и в 0.41.11. Храните ключи вне папки IWE, например в `~/.secrets/`.
- Проверка опасных команд смотрит только на текст команды и не видит путь, спрятанный в переменную.
- Ручная проверка на macOS ещё не закончилась.

Ещё одно: при запуске этой команды я снял режим лёгкого онбординга, теперь в среде действуют обычные правила. Если вам нужно, чтобы онбординг снова вёл разговор, его можно вернуть командой `bash .claude/scripts/light-onboarding-state.sh reset`.
