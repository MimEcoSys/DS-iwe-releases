## Что нашёл

1. **Красная обязательная проверка (блокирует выпуск).** «Проверка шаблона» упала на шаге регрессионных тестов, итоговая квитанция выпуска тоже красная. Чтобы снять блок, нужно открыть журнал упавшего задания с правами администратора, исправить и выпустить новый кандидат. Отдельную задачу на GitHub я не завёл: на этой машине создание задач запрещено.
2. **Лишний признак «можно запускать» (низкая важность).** У двух программ на Python (`scripts/artifactor.py`, `scripts/check-manifest-coverage.py`) обновление ставит этот признак, хотя в хранилище его нет. Так работает правило «файл с первой строкой `#!` делаем запускаемым». Я заметил это после круга «откат и возврат»: в копии шаблона эти два файла отмечаются изменёнными. На содержимое и работу это не влияет.
3. **Отказ от отката считается успехом (замечание).** Если на вопрос об откате ответить «нет», обновление завершается без кода ошибки. Файлы при этом не трогаются, ничего не ломается.
