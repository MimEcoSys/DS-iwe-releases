**Как я искал**

- Затруднение: как с нуля вывести закваску для хлеба.
- Ключевые слова: sourdough, starter(s), bread(s), ferment / fermentation / fermenting, culture(s), leaven, yeast. Русские слова «закваск» и «хлеб» не понадобились, потому что своих баз знаний нет.
- Где искал: по названиям всех 1143 записей свода (FPF, редакция b223469) и по 11 процессам описания предметной области (SPF, редакция 57dc3bf).

**Итог:** метода нет.
