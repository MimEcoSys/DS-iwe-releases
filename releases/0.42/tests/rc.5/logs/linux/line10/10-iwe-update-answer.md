## Обновление IWE: v0.41.11 → v0.42.0

**Что нового:**
- **Поиск метода** (`/find-method`, пока экспериментальный). Вы описываете затруднение, агент подбирает способ действия из FPF и ваших паков, приводит дословный фрагмент источника и ведёт по шагам. Если подходящего метода нет, он так и говорит и не придумывает план.
- **Лёгкий онбординг** (`/onboarding`). Новый человек за один разговор разбирает свою задачу методом из библиотеки. Правила рабочей среды на него в это время не действуют.
- **Уведомления в Telegram** теперь отправляет одна команда (`scripts/iwe-notify`). Если подключить свой шлюз уведомлений, рутинные сообщения будут приходить одной сводкой.
- **Linux и WSL2.** При установке фоновые роли (Стратег, разборщик) снова ставятся сами, без ручной настройки.

**Что изменилось в поведении:**
- **Агенту запрещено больше опасных команд.** Без вашего участия он больше не может удалять найденное через `find`/`xargs` или записывать в файл через `git diff --output`. Через `find -exec` теперь разрешены только команды чтения. Удалять ветки и менять адрес хранилища агент тоже не может.
- **Откат на прошлый выпуск** всегда просит ввести `ROLLBACK`, на любом канале обновления. С ключом `--yes` откат не выполняется вообще. Файлы более нового выпуска при откате переносятся в резервную копию.
- Слова «заливай» и «запуши» больше не запускают закрытие сессии.
- Правило «читать только открытые фазы» теперь по умолчанию действует для любой карточки РП, а не только для зонтичных.
- Новый РП можно не добавлять в план недели: для этого есть отдельный флаг и параметр.

**Исправления:**
- Проверка свежести хранилища при первом обращении больше не падает с ошибкой «файл не найден».
- В Windows (Git Bash) обновление больше не останавливается после первой записи.
- Закрытие сессии больше не падает из-за конфликта при отправке в хранилище.
- Подсчёт времени через WakaTime снова работает: раньше сервис отвечал отказом.

**Известные ограничения** (из описания выпуска):
- Команды чтения разрешены агенту без подтверждения. Поэтому он может прочитать файл с ключами (например, `.env`) внутри папки IWE. Храните ключи вне этой папки, например в `~/.secrets/`. Так было и в 0.41.11, исправление готовится отдельно.
- Проверка опасных команд видит только текст команды. Путь, спрятанный в переменную, она не распознаёт.
- Вручную выпуск проверили только на Linux. Ручная проверка на macOS ещё идёт.

Полный список изменений лежит в разделе `[0.42.0]` (в `FMT-exocortex-template/CHANGELOG.md`), а описание выпуска для пользователя (в `FMT-exocortex-template/docs/releases/0.42/README.md`).
