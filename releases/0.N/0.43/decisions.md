## Условие нарезки

Нарезка 0.43 возможна только после выхода 0.42.2: программа выпуска шаблона выпускает коммит основной ветки, дерево которого совпадает с деревом проверенного кандидата ([план](plan.md), раздел «Правило»). 0.42.2 вышел 25.11.2026, поэтому условие выполнено. Остальные условия нарезки: у каждой открытой строки [бэклога](../../backlog.md) есть исход на этот выпуск (действие 1г, сейчас открыто) и у каждого открытого обращения шаблона есть исход (действие 1в).
