# Выпуск 0.43: новые возможности по итогам голосования

Карточку завёл Разработчик 26.11.2026. Страница рассказывает о выпуске простыми словами: что в него войдёт и при каких условиях. Срок выхода не назначен: 0.43 собирается после исправительного выпуска [0.42.2](../0.42.2/README.md), который вышел 25.11.2026. Решения о составе и проверке принимает Выпускающий; пока они не записаны в [decisions.md](decisions.md), эта страница ничего не обещает сверх [плана](plan.md).

## Что за выпуск

- **0.43** собирает новые возможности, за которые люди проголосовали 21.11.2026: проголосовали 29 человек ([итоги голосования](vote.md)). В исправительные выпуски новые возможности не попадают, поэтому они ждали очереди.
- **Выпускающий:** `TserenTserenov` (решение 21.11.2026).
- **Состояние:** выпуск готовится. Состав утверждён 21.11.2026, форма решений, протокол проверки и чек-лист заведены 26.11.2026: [decisions.md](decisions.md), [protocol.md](protocol.md), [checklist.md](checklist.md). Список кандидатов (`candidates.md`) пока не собран: его строит программа из файла передачи Разработчика, а для 0.43 этот файл ещё не подготовлен.

## Что войдёт

В выпуск попадает только то, что прошло проверку. Голоса определили порядок, но не заменяют проверку.

| Возможность | Что получит человек | Условие входа |
|---|---|---|
| Разбор проекта (18 голосов) | Агент проходит проект по чек-листу и называет три главных пробела, у каждого сказано, что делать | перенос в шаблон и проверка |
| План дня из плана недели (16 голосов) | Задачи, перенос со вчера, часы и пометки в плане дня берутся из плана недели; если что-то не сходится, программа пишет об этом в самом плане | перенос в шаблон и проверка |
| Базы знаний других авторов (14 голосов) | Можно подключить базу другого автора только для чтения и искать по ней вместе со своей | человек, который не автор, ставит шаблон, подключает базу и находит в ней ответ; иначе возможность уходит в 0.44 |
| Входящие рабочего продукта разбираются до его закрытия | Рабочий продукт нельзя закрыть, пока не разобраны его входящие записи | вернуть из отложенного в 0.42.2 вместе с программой закрытия |
| Раздача работы нескольким агентам (16 голосов) | Независимые подзадачи можно раздать сразу нескольким ИИ-агентам; из четырёх схем переносится одна | живой прогон на установке шаблона, который делает не автор; иначе в 0.44 |
| Забытые наработки (7 голосов) | При закрытии недели агент показывает несохранённые правки и файлы вне хранилищ | если перенос не задержит выпуск |
| Часы по направлениям и близкие сроки (7 голосов) | Видно, сколько часов набрано по каждому направлению недели, и напоминания о близких сроках | только если после починки у автора перенос не задержит выпуск |

Не войдёт: ИИ-наставник в чате IWE (программа для IWE ещё не написана) и самостоятельная проверка гипотез (на деле не применялась).

## Как идёт работа над выпуском

1. После выхода 0.42.2 в основную ветку шаблона вливается новое для 0.43.
2. Разработчик разбирает [бэклог](../../backlog.md) и открытые обращения, Выпускающий решает, что берём (действия 1в и 1г [чек-листа](../../../method/release-checklist.md)).
3. Выпускающий называет снимок, Разработчик собирает кандидата, начинается проверка по [протоколу](protocol.md).
4. После выхода выполняются действия 17а–28 чек-листа. Выпуск закрыт, когда ни одна из этих строк не остаётся открытой: проверяет `python3 tools/release-checklist.py --closure --release 0.43`.
