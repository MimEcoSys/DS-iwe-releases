## Долг конвейера выпуска (цель: 0.43 собирается без ручной доводки)

Источник — Ф276 по итогам 0.42; порядок не определён.

1. Номера версий не вписывать руками в программы и описания (сначала решить, откуда программа берёт текущую версию).
2. Шаги после выхода — в описании процесса; программа чек-листа показывает шаги 7–9 (**сделано** в запросе DS-iwe-releases #73, ждёт слияния).
3. Одна программа собирает входные данные выпуска (состав, журнал, табло).
4. Перевод: проверка «нет кириллицы» по всему английскому дереву на каждом запросе на слияние, а не только на основной ветке.
5. Журнал изменений без конфликтов между параллельными запросами.
6. Срочная рассылка о безопасности: живая проверка доставки как шаг выпуска (починка бота — РП-7).
7. Выпуск без остановки основной ветки (Ф268) и проверка на macOS программой выпуска до раздачи людям (Ф271): по итогам 0.42 именно переход с 0.36 и macOS дали две пересборки (rc.10 и rc.11), см. [итог 0.42](../0.42/retro.md).
8. Сборка рабочей среды автора не должна перезаписывать корневые файлы-источники (п.8 Ф276).
9. Проверка объёма горячих инструкций (`verify-context-budget.sh`) красная: 21,5K при пределе 20K; владелец — РП-7.

Пункт 10 Ф276 (ссылки «Источник» на табло ведут в закрытый репозиторий) проверен 18.11: в генераторе закрытые источники помечены как непубличные, на страницах ссылок на закрытый репозиторий нет.
