🔄 Обновление шаблона IWE 0.42.1 1. Запрос перед перезаписью файла — Если агент перезаписывает файл через вывод команды, которая обычно разрешена без запроса, теперь он сначала спросит разрешения. Раньше так можно было незаметно стереть содержимое рабочего файла. 2. Онбординг не сбросится случайно — Сброс лёгкого онбординга больше не разрешён без запроса, а в установке, где уже есть работа, он без явного подтверждения ничего не меняет. В свежей установке сброс работает как раньше. 3. Зелёная строка обновления по утрам — В каркасе открытия дня строка «Update IWE» снова зелёная, когда обновлений нет. Раньше она каждое утро была жёлтой и попадала в «Требует внимания». 4. Изолированные сессии доходят до сервера — Изолированная копия рабочей папки снова отправляет коммиты на сервер и убирается при закрытии сессии. Коммиты уходят в основную ветку хранилища, даже если она называется не main. 5. Рабочие команды в скиллах — В памяти и скиллах больше нет незаменённых заготовок путей, поэтому команды закрытия недели и стратегической сессии снова работают. 6. Без ложного «план не опубликован» — Вечерняя проверка после закрытия дня больше не присылает ложное сообщение «План дня не опубликован сервером», если план уже перенесён в архив. Все изменения выпуска Как обновить: скажите своему Claude «обнови мой экзокортекс» или выполните в терминале bash update.sh
