# Выпуск 0.42.1: исправительный

Карточку завёл Разработчик 18.11.2026. Здесь коротко, что это за выпуск и где что смотреть. Решения о составе и выходе принимает Выпускающий; срок и состав эта страница не обещает. Общий порядок любого выпуска — [схема конвейера](../../../method/pipeline.md).

## Что за выпуск

- **0.42.1** — исправительный выпуск после 0.42. Новых возможностей в него не берут: только исправления ошибок и долг проверок (решение Выпускающего 18.11.2026).
- **Что входит по решениям на 18.11.2026:** исправления безопасности по итогам проверки 0.42 и запись памяти агента без подтверждений ([обращение #1487](https://github.com/TserenTserenov/FMT-exocortex-template/issues/1487)). Полный состав объявит Выпускающий.
- **Всё новое** отложено в [0.43](../0.43/plan.md) и ждёт голосования.
- **Состояние:** проверяется. В шаблоне есть ветка `release/v0.42.1` и метки сборок-кандидатов `v0.42.1-rc.1` … `v0.42.1-rc.8`; выпуск пока не опубликован.

## Где что лежит

Файлы появляются по шагам [конвейера](../../../method/pipeline.md), как у прошлых выпусков (схема папки — [releases/README.md](../../README.md)): форма решений `decisions.md`, протокол проверки `protocol.md`, доказательства в `tests/rc.<K>/`. Пока их здесь нет, значит, шаг ещё не сделан в этом репозитории; пустых файлов не заводят.
