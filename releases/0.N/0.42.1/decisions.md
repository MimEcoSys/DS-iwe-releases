## Аудит кода rc.16 (Аудитор кода, ИИ-агент Кодекс, 20.11.2026)

Прочитал разницу `v0.42.0...v0.42.1-rc.16`. Итог Аудитора: «блокирует: отправка на сервер при закрытии без отдельного вопроса; ключ DeepSeek в окружении процесса». Сверка Разработчика рядом с каждой находкой.

1. **Высокая, по оценке Аудитора: закрытие изолированной сессии отправляет её коммиты на сервер без отдельного вопроса** (`scripts/session-guard.sh` строки 453 и 2671; команда закрытия разрешена без вопроса в `.claude/settings.json`). Сверка Разработчика: и отправка при закрытии, и разрешение без вопроса были в 0.42.0; #1578 только научил закрытие находить программу отправки на обычной установке, где раньше она не находилась и копии оставались неубранными. Это задуманное поведение закрытия, а не новое право. Решение — Выпускающему.
2. **Средняя: диспетчер фоновых ролей передаёт ключ DeepSeek в окружение процесса DeepSeek Harness** (`extensions/agent-inbox/scripts/iwe-agent-dispatcher.py` строки 901 и 992). Новое в 0.42.1 (#1504). Сверка Разработчика: ключ нужен самому DeepSeek Harness для работы; путь включается только при выборе DeepSeek, по умолчанию фоновые роли идут через Claude. Решение — Выпускающему вместе с вопросом состава ниже.
3. **Средняя: установщик навыков для DeepSeek Harness считает мост установленным по одной метке в тексте** (`setup/install-dsh-skills.sh` строка 85). Новое в 0.42.1 (#1534).
4. **Низкая: после возврата на 0.42.0 запись моста в `~/.dsh/cordis.patch.yml` остаётся** (`update.sh` строка 3045). Новое в 0.42.1 (#1534); в записи журнала изменений сказано удалить вручную.

Шесть файлов Аудитору не показаны: их не пропустил местный фильтр личных данных (это программы работы с секретами и тест словаря); их правки он видел в разнице.
