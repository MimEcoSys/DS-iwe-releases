## Что получилось

- Состав и выпуск разведены: «режем» по снимку, дальше только исправления на ветке выпуска; выпущено дерево последней проверенной сборки (`release.yml` сверяет).
- Решения Выпускающего записаны в одной форме и проверяются программой перед слиянием (`check_decisions.py --require-final`).
- Независимая атака дала вердикт по тому же дереву, что вышло.

## Что не получилось

- Тестировщика macOS на последней сборке не было; шесть обязательных строк вышли оговорками в анонсе, а не живыми отметками.
- Windows не проверялся: тестировщика нет, выпуск Windows не обещал.
- Выпускающий и Разработчик — один человек: обязательность проверок держалась на программах, а не на независимости ролей.
- Защиту проверяли только в формате запросов Claude Code и только внутри папки IWE. Так прошли два обращения, сработавшие по порогу отката: в Kimi Code защита секретных файлов не давала читать и править файлы (TserenTserenov/FMT-exocortex-template#1657), а проверка сессии не давала сохранить личный репозиторий вне папки IWE (#1658). Исправлены в 0.42.2.
- Итоги окон наблюдения 0.42 и 0.42.1 записаны с опозданием (27.11.2026, окно 0.42 кончилось 23.11): у формы решений 0.42 не было строки для итога окна.

## Уроки — уже внесены в описание конвейера

- Перенос отметки со старой сборки на новую — только отдельной записью решения ([protocol.md](protocol.md), найдено на `rc.15`).
