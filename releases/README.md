# Выпуски

Здесь хранят все выпуски шаблона IWE: что сделано, что сейчас, что будет — и всё, чем проверяли каждый выпуск.

| Вопрос | Где ответ |
|---|---|
| Что уже вышло | [HISTORY.md](HISTORY.md) |
| Что сейчас | [NOW.md](../NOW.md) |
| Что будет | [NEXT.md](NEXT.md) |
| Все версии одним списком | [INDEX.md](INDEX.md) (тот же список для сайта и бота — [catalog.json](catalog.json)) |

## Что лежит в этой папке

| Путь | Что это | Кто пишет |
|---|---|---|
| `index.yaml` | единственный список версий: номер, состояние, дата проверки, ссылки | Разработчик |
| `INDEX.md`, `HISTORY.md`, `NEXT.md`, `catalog.json` | списки выпусков для людей, сайта и бота | программа ([program/release_catalog.py](program/release_catalog.py)) |
| `developer-handoff.yaml` | правки «Ещё не выпущено», подготовленные Разработчиком к передаче Выпускающему; из него собирается `candidates.md` выпуска | Разработчик |
| `program/` | программы выпуска: каталог, проверка решений, чек-лист, раскладка путей (`layout.py`) и их тесты | Разработчик |
| `<X>.N/` | выпуски, сгруппированные по первому числу версии: `0.N/` — все 0.x, дальше `1.N/`, `2.N/` | — |
| `<X>.N/<N>/` | папка одного выпуска; адрес не меняется | см. ниже |

## Папка выпуска

Файлы появляются по шагам [конвейера](../method/pipeline.md); у прошлых выпусков есть только то, что тогда велось, — пустых файлов для них не заводят.

| Файл | Что это | Появляется на шаге | Кто пишет |
|---|---|---|---|
| `vote.md` | варианты голосования за состав | до снимка | Разработчик |
| `plan.md` | черновик плана будущего выпуска: что переходит из прошлых, долг конвейера, решения Выпускающего; состав и срок не обещает | до снимка | Разработчик |
| `README.md` | карточка выпуска: что за выпуск, где что лежит, что сделать по шагам | 1, снимок | Разработчик |
| `candidates.md` | что можно взять: кандидаты с рекомендацией Разработчика | 1–2 | программа |
| `decisions.md` | решения Выпускающего: состав, блокирующие строки, оговорки, итог | 3 и 7 | Выпускающий |
| `protocol.md` | протокол проверки сборки: строки, кто проверяет, что блокирует | 4–5 | Разработчик предлагает, Выпускающий решает |
| `tests/rc.<K>/` | доказательства: отметки тестировщиков, отчёт атаки, журналы, проверочные скрипты — папка на кандидата | 5–6 | тестировщики, проверяющий red team |
| `shipped.md` | что вышло: записи списка изменений выпуска; после выхода не меняется | 8 | программа |
| `retro.md` | итог выпуска: цифры, что получилось и что нет, уроки | 8, после окна наблюдения | Выпускающий (черновик — Разработчик) |
