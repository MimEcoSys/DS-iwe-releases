# Выпускающий шаблона IWE — с чего начать

Короткая памятка новому Выпускающему: что ты делаешь, зачем, и как начать за один вечер. Подробности — по ссылкам внизу.

## Что ты делаешь и зачем

Шаблон IWE — набор правил, навыков и программ, который люди ставят себе на компьютер и обновляют одной командой. Каждое обновление попадает сразу ко всем. Если в него проскочит ошибка, она сломает работу у всех.

Разработчик пишет изменения и вливает их в основную ветку шаблона. **Ты решаешь, какие из них и когда получат пользователи, и следишь, чтобы вышла ровно та сборка, которую проверили.** Для этого ты:

- отбираешь состав выпуска;
- назначаешь тех, кто проверяет сборку, и решаешь, какие проверки обязательны;
- по каждой найденной проблеме решаешь: чинить, принять как оговорку или отложить правку;
- нажимаешь кнопку выпуска, когда всё обязательное пройдено;
- после выхода смотришь, нет ли серьёзных жалоб, и при необходимости решаешь об откате.

Код ты не пишешь и не чинишь. Решения записываешь в форму решений выпуска — обычную таблицу в этом репозитории. Механику (ветки, метки, проверки) делают программы и Разработчик; часть шагов программа просто не пропустит, если что-то забыто.

Роль описана в Паке платформы: [DP.ROLE.120 «Выпускающий»](https://github.com/MimEcoSys/PACK-digital-platform/blob/main/pack/digital-platform/02-domain-entities/DP.ROLE.120-release-issuer.md).

## Что нужно от твоего IWE

Считаем, что свой IWE у тебя уже есть. Для роли Выпускающего он должен работать **на твоём компьютере**, а не в браузере:

| Нужно | Зачем |
|---|---|
| VS Code с агентом IWE (Claude Code или другой агент, который читает файлы и запускает команды в терминале) | агент читает этот репозиторий, готовит решения и запускает программы проверки |
| `git` и GitHub CLI `gh` с выполненным входом (`gh auth status`) | скачать этот репозиторий, смотреть запросы на слияние, ставить свои правки формы решений |
| `python3` с пакетом PyYAML (`python3 -m pip install pyyaml`) | программа проверки решений `ops/check_decisions.py` |

Браузерная версия IWE (сайт или чат-клиент) для этой роли не подходит: в ней агент не может скачать репозиторий и запустить проверки. Ей можно пользоваться, чтобы читать документы и тему выпуска.

Тестировщику нужно больше (Мак, отдельная учётная запись) — это в [его инструкции](tester-macos.md).

## Быстрый старт

1. **Проверь IWE** по таблице выше: в терминале `git --version`, `gh auth status`, `python3 -c "import yaml"` — все три без ошибок.
2. **Доступы.** Пришли владельцу шаблона свой логин GitHub. Тебя добавят в команду `iwe-release-lead` организации MimEcoSys и дадут права в репозитории шаблона (запуск проверок и слияние). Нужен ещё доступ к Зулипу МИМ — там тема каждого выпуска.
3. **Этот репозиторий у себя:**
   ```bash
   cd ~/IWE && git clone https://github.com/MimEcoSys/DS-iwe-releases
   ```
4. **Попроси агента прочитать** — в VS Code открой папку `~/IWE`, в панели агента напиши:
   > Я Выпускающий шаблона IWE. Прочитай DS-iwe-releases/CLAUDE.md и всё, что он велит загрузить, затем releases/<номер выпуска>/README.md, и скажи, какие решения от меня нужны сейчас.

   Агент прочитает лист этапов и инструкцию Выпускающего и ответит по текущему выпуску.
5. **Открой папку текущего выпуска** `releases/<N>/` — с её README и начинается работа над выпуском.
